# 速算题本生成器 — 开发计划书

> 版本: v0.1（草案） · 日期: 2026-08-29 · 状态: 待评审

## 一、项目背景与目标

资料分析是行测中分值密度最高、提分最快的模块，核心能力是**速算**。备考者日常刷题需要大量、可重复的速算训练素材，但市面题本要么是静态成套题（做完无新题），要么不含速算方法解析。

本功能在「公考小工具」内新增**速算题本生成器**：基于花生十三公开教学体系（ABRX 四要素 + 截位直除 / 415 份数 / 假设分配三大速算方法），按用户选择的题型、题量与难度，**随机生成**覆盖资料分析全部场景题型的题本 PDF，含答案解析与速算方法提示，可反复生成、无限刷题。

### 核心价值

| 痛点 | 本功能解法 |
|------|-----------|
| 练习素材有限、易做完 | 参数化随机生成，每次不同 |
| 不知道用什么速算方法 | 每道题附「推荐速算方法 + 计算过程」 |
| 刷题不体系化 | 题型按 ABRX 体系分组，可针对性专项训练 |
| 难度不可控 | 三级难度（基础/进阶/挑战）逐步递进 |

## 二、题型体系设计（核心）

题型以花生十三资料分析体系为纲，划分为 **5 大模块 26 种子题型**：

### 模块 A：基础运算（口算敏感度）

| 子题型 | 说明 | 示例 |
|--------|------|------|
| A1 加减乘除口算 | 2–3 位数的四则口算 | 3247 + 5689 = ? |
| A2 特殊分数互化 | 分数 ↔ 百分比互化 | 1/8 = ?% |
| A3 尾数法/首数法 | 选项尾数/首位不同的速算 | 4567 + 3456 + 2345 尾数 |
| A4 凑整估算 | 分母凑整简化除法 | 4567 ÷ 998 ≈ ? |

### 模块 B：ABRX 四要素（核心骨架，8 种已知→求解组合全覆盖）

| 编号 | 已知 | 求解 | 推荐方法 | 示例 |
|------|------|------|----------|------|
| B1 | A、R | B 基期量 | 截位直除 | 现期 8872 亿，同比 -22.9%，求基期 |
| B2 | A、X | B 基期量 | 直接减 | 现期 12000，增长 2000，求基期 |
| B3 | A、R | X 增长量 | **415 份数法** | 现期 48810，同比 +4.6%，求增长量 |
| B4 | B、R | X 增长量 | 直接乘 | 基期 4000，+25%，求增长量 |
| B5 | A、B | R 增长率 | (A-B)/B | 现期 12000、基期 10000，求增速 |
| B6 | A、X | R 增长率 | X/(A-X) | 现期 5000、增长 1000，求增速 |
| B7 | B、R | A 现期量 | **假设分配法** | 基期 5460，+14%，求现期 |
| B8 | B、X | A 现期量 | 直接加 | 基期 8000、增长 900，求现期 |

> 设计要点：B1–B8 覆盖 ABRX 四要素两两组合的全部场景，是题本的骨架，默认全选。

### 模块 C：速算方法专项（方法训练）

| 子题型 | 说明 |
|--------|------|
| C1 截位直除专项 | 除法估算，选项差距（首位/前两位/前三位）驱动截位位数 |
| C2 415 份数法专项 | 已知现期+增长率求增长量，比例化简训练 |
| C3 假设分配法专项 | 求基期/现期，乘法分配训练 |
| C4 分数比较法专项 | 多分数大小比较（通分/交叉相乘/中间值） |
| C5 增长率比较专项 | 多对象增速比较（现期/基期已知） |

### 模块 D：高频考点题型（真题场景）

| 子题型 | 考点 | 公式要点 |
|--------|------|----------|
| D1 现期比重 | 部分/整体 | 一步除法 |
| D2 基期比重 | 部分现期/整体现期 × (1+整体R)/(1+部分R) | 记整体 R 在分子 |
| D3 比重升降判断 | 部分R vs 整体R | 定性判断 |
| D4 比重差计算 | 部分/整体 × (部分R-整体R)/(1+部分R) | 单位是百分点 |
| D5 现期平均数 | 总量/份数 | 一步除法 |
| D6 平均数增长率 | (总量R-份数R)/(1+份数R) | 分子为增长率差 |
| D7 倍数计算 | 是几倍 A/B、多几倍 A/B-1 | 二者差 1 |
| D8 基期倍数 | (A/B) × (1+B的R)/(1+A的R) | 换位记忆 |
| D9 年均增长率 | (末期/初期)^(1/n)-1 | n 为年份差，二项式近似 |
| D10 拉动增长率/贡献率 | 部分增量/整体基期；部分增量/整体增量 | 两者与整体增速可互推 |

### 模块 E：综合训练（实战场景）

| 子题型 | 说明 |
|--------|------|
| E1 单材料多题 | 随机生成一张简表（如各省份 GDP/产量），配 3–5 道 ABRX/比重/平均数题，模拟真题「材料+题目」形态 |
| E2 综合分析题 | 每篇材料最后一题，「以下说法正确/错误的是」，4 个选项分别验证 |

### 题型配比建议（默认值，可改）

| 模块 | 默认题量占比 | 说明 |
|------|-------------|------|
| A 基础运算 | 10% | 热身 |
| B ABRX 四要素 | 35% | 骨架，必练 |
| C 速算方法专项 | 20% | 方法训练 |
| D 高频考点 | 25% | 真题场景 |
| E 综合训练 | 10% | 实战整合 |

## 三、数值生成引擎（工程核心）

### 3.1 难度分级

| 难度 | 数值位数 | 增长率样式 | 干扰项 | 适用 |
|------|----------|-----------|--------|------|
| 基础 | 3–4 位整数 | 整十整五（10%/20%/25%/50%） | 单一错误 | 方法入门 |
| 进阶 | 4–5 位整数 | 一位小数（4.6%/8.4%） | 常见易错陷阱 | 提速训练 |
| 挑战 | 5–6 位 + 单位换算 | 任意 + 负增长 + 多步 | 复合陷阱 | 实战模拟 |

### 3.2 生成约束（保证"好算"）

- 除法：分子/分母构造为可截位直除的形态（商为 2–3 位有效数字，选项由真实商按截位规则生成）
- 415 份数：构造 现期 = 每份 × (100+R) 逆向生成，保证可整除或近似整除
- 选项生成：正确答案 + 3 个基于**常见错误**的干扰项（截位误差、基期/现期混淆、多几倍/是几倍混淆、百分点/百分比混淆、单位换算错误、增长率正负号错误），干扰项与正确项首位分布随机化
- 单位体系：万/亿/万吨 随机注入，个别题含 ‰ 与单位换算陷阱
- **随机种子**：生成器接受 seed 参数，同种子可复现同一套题（便于教学演示与回归测试）

### 3.3 解析内容设计（特色）

每题输出：
1. 公式（ABRX 符号化）
2. 推荐速算方法（截位直除/415 份数/假设分配/直接乘）
3. 分步计算过程（含截位细节）
4. 易错点提示（时间范围/单位/是几倍 vs 多几倍 等）

## 四、PDF 题本结构

```
速算题本（A4）
├── 封面页：题本标题、难度、题量统计、生成日期
├── 使用说明页：速算方法速查表（口诀 + 适用场景）
├── 题目页（按模块分区，每题带序号）
├── 答案速查表页（仅选项，快速对答案）
└── 详细解析页（公式 + 速算过程 + 易错点）
```

- 排版复用 `tools/pdf_converter/core/generator/font_manager.py` 的 FontManager 注册中文字体
- ReportLab 输出（与 answer_sheet、pdf_generator 技术栈一致），无新依赖
- 可选项：是否包含答案速查表 / 详细解析（默认包含）

## 五、模块架构

遵循项目 `tools/<name>/core + ui` 惯例：

```
tools/quick_math/
├── __init__.py
├── docs/
│   └── plan.md                # 本计划书
├── core/
│   ├── __init__.py
│   ├── models.py              # 数据模型：Question / AnswerOption / QuickMathConfig / 题型枚举
│   ├── number_pool.py         # 数值随机生成器（难度控制、"好算"约束、单位注入）
│   ├── generators/
│   │   ├── __init__.py
│   │   ├── base.py            # BaseGenerator 抽象基类（generate() -> Question[]）+ 干扰项工厂
│   │   ├── basic_arithmetic.py    # 模块 A
│   │   ├── abrx.py                # 模块 B（B1–B8 八个生成器）
│   │   ├── speed_methods.py       # 模块 C
│   │   ├── key_points.py          # 模块 D
│   │   └── comprehensive.py       # 模块 E（材料生成 + 组题）
│   ├── assembler.py           # 配比组装：题型/题量/难度/seed → 题单（含乱序选项）
│   └── pdf_generator.py       # ReportLab 排版：封面/说明/题目/答案/解析
└── ui/
    ├── __init__.py
    └── widget.py              # 设置界面 + 生成流程（back_requested / status_message 信号）
```

### 数据流

```
widget.py (用户配置: 题型多选/题量/难度/seed/格式)
    ↓
assembler.py (配比 → 各 generator 调用)
    ↓
generators/* (number_pool 取数 → 题目+选项+解析)
    ↓
pdf_generator.py (ReportLab 排版 → PDF bytes)
    ↓
QFileDialog 保存 → 完成提示
```

## 六、UI 设计

`QuickMathWidget`（QStackedWidget 新页面，风格对齐现有工具页）：

| 区域 | 控件 |
|------|------|
| 顶部 | 标题 + 返回按钮（back_requested） |
| 题型选择 | 5 组复选框（模块 A–E），默认全选；组内子题型可单独勾选 |
| 题量设置 | 每子题型题量 SpinBox（1–50，默认 5）；或总题量 + 自动均分 |
| 难度 | 单选按钮：基础 / 进阶 / 挑战（默认进阶） |
| 格式选项 | 含答案解析 CheckBox（默认勾选）、含答案速查表 CheckBox、随机种子 SpinBox（留空=随机） |
| 题本信息 | 题本标题 QLineEdit（默认"资料分析速算题本"） |
| 操作区 | 「生成题本 PDF」主按钮 → QFileDialog 另存为 |

生成过程为纯计算 + 排版，量级秒级完成，无需后台线程（题量极大时可后续优化）。

### 主窗口集成

## 九、风险与注意事项

1. **生成"好算"数字的复杂度**：逆向构造（先定答案再定题目数据）是数值引擎的关键，需要每个题型单独设计构造算法，是工作量最大的部分（对应 M1 工期占比）。
2. **难度平衡**：干扰项不能太离谱（一眼排除）也不能太接近（计算量失控），按难度分级控制干扰项偏移比例。
3. **排版长度**：题目+解析页数可能较多（默认 25 题约 6–8 页），需限制解析文本长度，必要时解析页用小字号。
4. **字体依赖**：复用 FontManager 的 Windows 系统字体方案（SimSun/SimHei），与现有工具一致，无新依赖。
5. **与错题本联动（远期）**：可考虑把错题标记的数据结构留给未来对接，本期不做。
